Creiamo un "mini" web-server in Java con queste limitazioni:

le pagine html sono memorizzate nella carella c:/mioserver del server (root del sito) (lato server)

il server gestisce solo richieste HTTP di tipo "GET" e nome della pagina html

il server risponde con un messaggio in cui è incluso il codice di stato (ok oppure not found) e alcune info dell'HEADER, ovvero: Server, Date, Content-Length, Content-Type. Poi invierà il file HTML con un flusso di byte

il server chiude la connessione al termine di ogni richiesta HTTP (quindi NON supporta la ricezione di più richieste sulla stessa connessione)

il server attende richieste sulla porta 12345
